## 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/geloxh/3e-hitech-solutions-stable-website
   cd 3e-hitech-solutions-stable-website
   ```

2. **Open in browser**
   ```bash
   # Open index.html in your preferred browser
   open index.html
   ```

3. **For development**
   ```bash
   # Use a local server (recommended)
   npx serve .
   # or
   python -m http.server 8000
   ```

## 🔧 Customization

### Colors
Edit CSS variables in `sss/a.css`:
```css
:root {
  --primary: #0056b3;
  --secondary: #00a0e9;
  --accent: #4db5ff;
}
```

### Content
- Update company information in HTML files
- Replace images in `src/imgs/` directory
- Modify contact details in footer sections
